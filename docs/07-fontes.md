- [GTD Weekly Review: Step-by-Step Guide + Checklist](https://www.asianefficiency.com/productivity/gtd-weekly-review/) — estrutura da revisão semanal

- [What are Work In Progress Limits in Personal Kanban?](https://flow-e.com/personal-kanban/wip/) — limites de WIP contra a dispersão

## Evidência científica

- [Implementation-intention encoding in a prospective memory task enhances spontaneous retrieval of intentions](https://pubmed.ncbi.nlm.nih.gov/22897132/) — Gollwitzer; base das âncoras *quando/onde*
- [Committing to implementation intentions: Attention and memory effects for selected situational cues](https://link.springer.com/article/10.1007/s11031-011-9261-6) — pistas situacionais recordadas melhor após 15 min e após 2 dias
- [The Effect of Implementation Intentions on Prospective Memory Commission Errors](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10375946/) — sob carga cognitiva
- [Zeigarnik Effect: meta-análise](https://yukaichou.com/behavioral-analysis/zeigarnik-effect-incomplete-tasks-memory-tension/) — Masicampo & Baumeister: **um plano concreto liberta a tensão da tarefa aberta, mesmo antes de a concluir**. É a justificação central do ritual da véspera.
